The World in One Day — 21 November 2026: a deterministic program that draws a 1024x1024 PNG newspaper front page summing up the world news of Saturday 21 November 2026. Seven real stories: a Russian missile lands in Poland, Wall Street plunges as the AI rally unravels, Cyclone Akvan slams into the Odisha coast, Bolsonaro is rushed to hospital, GTA VI smashes the first-day sales record, COP31 talks enter their final stretch, and a suicide blast kills five at a checkpoint in Pakistan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program uses only the Node standard library (no network, no dependencies) and writes `entry.png` (1024x1024, under 1 MiB) into the output directory. Two runs produce byte-identical output.
